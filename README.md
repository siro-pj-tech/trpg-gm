LLM（ChatGPT, Gemini, Claude 等）を高度で没入感のある **TRPGゲームマスター（GM）** へ変貌させるシステムプロンプトおよび画像生成AI用プロンプトの自動作成Webツールです。

👉 **[TRPG_GMプロンプトジェネレーター「十六夜カラクリ」を試す（GitHub Pages）](https://siro-pj-tech.github.io/trpg-gm/)**

---

## ✨ 主な機能

1. **シナリオプリセット＆完全カスタム対応**
   * **王道ファンタジー**（魔王城へ向かう旅）
   * **和風あやかし伝**（妖王・天魔殿へ向かう旅）
   * **SFスペースオペラ**（銀河帝国へ向かう旅）
   * **完全カスタム**（世界観・目的・個別イベント・1〜20ターンの柔軟な上限設定）

2. **動的ステージ収束判定（3条件システム）**
   * 単純なターン制限ではなく、「イベント決着」「人間関係の変化」「次への動機獲得」の3つの達成状況をGMが内部判定して物語を自然に次の土地へ移行させます。

3. **未消化イベントの自動救済（未回収の種）**
   * プレイヤーがイベントを回避・無視した場合でも「未回収の種」として保持し、別の行動（探索や戦闘）に合わせて姿を変えて発生させます。

4. **二段階生成方式 (Two-Step Generation)**
   * GMは毎ターン「思考ステップ（内部判定・非表示）」を行った上で、「応答ステップ（プレイヤー出力）」を生成するため、ブレのない破綻のないGM進行が可能です。

5. **特殊操作＆音声会話モード最適化**
   * **疑義ルール**: 回答を `＊判定がおかしい＊` のようにアスタリスクで囲むとGMが補足・修正を行います。
   * **音声会話最適化**: リアルタイム音声会話時にも冗長にならずテンポ良く進行する調整ルールをプロンプトに網羅。

6. **ビジュアル画像生成プロンプト**
   * DALL-E 3やGemini向けに、テキストや文字を含まない美しい冒険の旅立ち一枚絵を生成するプロンプトを出力します。

## 🚀 使い方

1. `index.html` をブラウザで開きます。
2. 世界観シナリオ、主人公の設定、旅する3つの国、重要NPCを選択/ランダム入力します。
3. **「PROMPT GENERATE」** ボタンをクリックします。
4. **【手順1】画像生成プロンプト** をコピーして DALL-E 3 や Gemini などで送信し、ビジュアルを生成させます。
5. **【手順2】GM用プロンプト** をコピーして ChatGPT / Gemini / Claude などのチャットAIへ送信し、セッションを開始します！
